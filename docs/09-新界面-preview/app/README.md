# 作战室 · 完整面板（A 方向）

机场监控的新界面实现，9 个视图。双击 `index.html` 即可打开，不需要服务端、不联网。

## 打开方式

- 双击 `index.html`（`file://` 直接可用，数据随 `data.js` 一起加载）
- 地址栏 `index.html#nd` 之类的 hash 可以直接进某个视图，方便分享位置

## 九个视图

| hash | 视图 | 一句话 |
|---|---|---|
| `#ov` | 总览 | 一屏内回答：多少家活着、卡在哪、我该动谁 |
| `#exp` | 到期 | 按剩余天数升序，过期置顶，带流量进度 |
| `#al` | 告警 | 原始变更流，按类型筛选，可搜机场名 |
| `#hw` | 华为云 | 当前命中 + 历史台账 + 五维判定说明 |
| `#nd` | 节点 | 47 家左侧列表 + 右侧协议构成与节点明细 |
| `#lib` | 机场库 | 注册表 + 面板/内核/客户端版本 + 推荐站档案 |
| `#kn` | 知识 | 采集原理 / 判定口径 / 名词表 |
| `#an` | 分析 | 30 天趋势、地区分布、异常波动、ASN 归属 |
| `#run` | 运行 | 本轮心跳、陈旧度、日志尾巴、导出总账 |

## 交互

- 左侧导航切换视图，选中态用一块滑动的底板（不是每项各自高亮）
- 总览矩阵点任意机场 → 右侧抽屉：状态、原因、该做什么、协议构成、节点列表（可搜索、点「机场详情」换视图）
- 矩阵右上角有卡片尺寸 **小 / 中 / 大**：小=7 列紧凑扫读（一屏装完 47 家）、中=6 列默认（名称 13px、节点数 18px、带状态词）、大=5 列（多一行「可导出」）
- 节点视图左侧列表搜索 + 按可导出节点数排序；右侧明细内滚动
- 每个视图首屏有一次入场：主角先到，其余按阅读顺序跟上（≤600ms，切换回来不重播）
- 系统开了「减少动态效果」时全部直接到位

## 动效三处（按 oil-ui motion 规范）

1. **主操作反馈**：导航与筛选按下即位移 1px，选中立刻换底板；抽屉打开 260ms 滑入 + 遮罩淡入
2. **状态切换有来路**：导航底板随选中项移动；同一视图内筛选切换时内容不做交叉淡化，直接换
3. **首次进入一次出场**：KPI 数字 → 矩阵 → 底部分布，间隔 60ms

## 数据

`data.js` 由 `tools/gen_panel_data.py` 生成，源为 `data/last_run.json`、`data/sub_health.json`、`data/quota.json`、`data/analysis.json`、`data/client_versions.json`、`nodes/index.json`、`data/sitewatch.json`、`airports.yaml`、`credentials.yaml`。

只输出派生值与纯域名：不含量节点密码、uuid、订阅 token。生成后经正则自检（`eyJ` / `password=` / `subscribe?token` / `aead_key` / `auth_token` / 长 URL / 邮箱）全部 0 命中。

> 预览版是静态快照。接成正式面板时，`data.js` 换成插件 `/api/data` 轮询即可，渲染层不用改。

## 体检状态

九视图截图在 `shots/`。机械 lint：无控制台错误、无横向溢出、无加载失败；对比度全部 ≥ 6.0:1；首屏不出现「内容停在顶部、下方大片空白」。

总览高度：小尺寸 838px（一屏正好）、中尺寸 954px（约多出 100px，协议/地区两块要往下滚一点）、大尺寸更高。

保留两处刻意项：总览矩阵的彩色单侧边线（47 处，状态编码，同色只出现在状态位）；分析页 RDAP 组织名的大写英文（`AMAZON-SIN` 等，是数据本身不是界面标签）。
