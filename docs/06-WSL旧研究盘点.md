## 三、「10-14 五篇」方法论提炼：检测信号四分类

> 任务要求"四篇"的方法论提炼；10-14 实为五篇（方案总纲为收口综合，其余四篇为分支），合并提炼如下。

### 3.1 被动指纹（不触碰内容、不解密）

- **拓扑/会话统计**（协议无关，最强）：单端口海量连接 F1；源 IP/AS 分散度 F2；方向字节不对称 F3；超长连接>10min F5；端口集中度 F6；目的集中少数境外 F7；晚高峰 F8。核心洞察=拓扑形态（海量陌生源→单端口长连接→少数境外目的地）无正常业务对应物。
- **首包比特统计**（GFW 实证）：单字节置位密度 popcount/len∈[3.4,4.6]；前 6 字节可打印 ASCII；>50% 可打印；>20 连续可打印（取反即检测器）；Shannon 熵（首包/前三包）。
- **TLS 指纹族**：JA3（停维护，配 JA3S）、JA4/JA4H/JA4X、**JA4T/JA4TS（SYN 层 TCP 栈指纹，治 uTLS"浏览器衣服 OS 口音"）**；JA3 分布全 Go 无浏览器=强信号；UA 与 JA3 矛盾=实锤级。
- **TLS-in-TLS 嵌套握手**（最强单判据）：外层握手后紧跟内层 ClientHello（`^\x1[67]\x03`）；USENIX24 方法抗随机填充与多层封装。
- **包长/时序序列**：SPLT（载荷长度序列）+到达时间；包长分布/包间隔周期性/并发度/目的分散（NetFlow 四要素）。
- **证书与域名画像**：签发者=平台指纹（LE 短周期批量同模板）；自签/CN 不匹配（易被 Reality 绕过）；CT 日志平台变化曲线；批量注册域名关联。
- **订阅链路指纹**：URL 路径模式 `?token=&flag=clash|v2rayng`；内容格式（base64 URI/Clash YAML/sing-box JSON）；面板端点指纹；favicon MurmurHash；"去特征"行为本身。
- **帧级指纹**（需 TLS 终止/明文位置，CDN 运营方或本地终端视角）：VLESS 头 36B 结构；Trojan 首行 56 hex+CRLF；VMess（弱）；gRPC（中）。
- **DNS 侧**：查询长度/字符分布/子域基数（隧道类）；DoH 明文化对抗。
- **QUIC 侧**：Initial 包 SNI 明文可提取。

### 3.2 主动探测

- GFW 7 类：重放 R1（完全重放）/R2-R5（改指定字节段）+random NR1（长度三连 (n-1,n,n+1)）/NR2（恒 221 字节）；侧信道特征（>75% IP 多次探测、90% 少数源端口）。
- "对坏输入秒断"判别：正常服务挂起/拒绝，代理秒断——行为差即特征（VLESS 实验室已复现：Close 帧 88 02 03 e8）。
- CDN 运营方版：按日志路径回放 ws 升级→101+二进制流=实锤；101 后秒断同为特征；404 则换路径。
- 伦理/安全边界：对非自有资产主动探测受合规约束（方案总纲三硬约束之一）；对在用节点探测会惊动机场（实测一条备线 11 天死亡）。

### 3.3 遥测日志（云商租户视角）

- 华为云 12 数据源（字段级清单见遥测清单文档）：VPC 流日志（五元组+字节包数+direction+tcp-flag，10 分钟聚合）；CFW 流量/访问控制/攻击日志（**域名仅 dst_host 一处**）；ELB 访问日志（SNI/套件/RTT，无 JA3）；DNS 解析器日志（QueryName）；VPC 流量镜像（唯一报文级，转 Zeek/IDS）；HSS 主机指纹；CES/CTS 资源变更；Anti-DDoS 事件。
- 硬缺口：NAT 网关无会话日志（五元组不可得）；LTS 单字段 2KB/跨度 30 天/分析 24GB 上限；镜像规格受限。
- 关键认知：云商"数据中立"不提供厂商侧 DPI→流量侧判据要么租户自建（镜像+Zeek），要么本机/网关侧自采。

### 3.4 合规边界

- 法条框架：宪法 40 条通信秘密（常态解密无依据）→**只能元数据与流量特征**（五元组/时序/包长/SNI/DNS/JA3）；网安法 2026-01-01 条文重排（旧 47→新 49 等）；数安法 32；个保法 6。
- 云商合同：open proxy 定义（无认证+替他人转发）即违约点；处置三档（观察/通知整改/限制服务）。
- 处置原则：信号只能线索聚类+人工复核，不能单独定性；不静默删除、留证据链、watchlist、特征反哺；LLM 不碰 payload、结论必带 evidence_refs。
- 刑事/行政分野：用户侧多为行政违法；"提供工具/经营销售"才是刑事高危——检测目标应锚定经营端。

## 四、与 Jichang-Monitor 现有数据的结合点（离线验证清单）

> data/ 快照具备：`_resolved_ips`（节点域名解析结果）、`_rdap`（注册信息）、华为签名命中字段；4.4 万快照（3h 粒度时序）。研究目录的 CNAME/传输层 JSON 可与之交叉。以下 8 项均为**纯离线分析，不跑 run.py、不改代码**，可直接立项。

1. **端口画像重算**（对照 GFW/运营方端口先验）：对 2515 节点 server:port 分布做直方图——443 与 CF 段（2052-2096）/SS 传统段（8388）/面板段（54321 等）/自选高位段（30000+）的占比；产出"端口带"标签列。对应 F6 的配置版。
2. **SNI 伪装词表聚类**：基于传输层 JSON（sni 字段）+快照，把 SNI=update.microsoft.com/baidu.com/douyin-dpi.com/tbcache/对象存储/mozilla addons 等大站伪装域聚类打标；结合 tls.skip-cert-verify 计数（如 xm999 曾 73 个 skip=true）。**SNI 与 Host 分离、SNI≠解析域**的节点单独成类（REALITY/伪装直连候选）。
3. **真/假 CDN 判定重放**：用 D1 CNAME 后缀表+CF/CloudFront/华为边缘 IP 段知识，对 `_resolved_ips` 全量重算"是否真 CDN 边缘"；与 09-17 的 5 家真 CDN 结论对照，看两周快照里 CDN 归属漂移（机场换线是常态——实测一条备线 11 天死掉）。
4. **GeoDNS 藏死集合监测**：把 09-17 NXDOMAIN 的域名清单对当前 `_resolved_ips` 状态做差分——藏死集合的进出变化本身就是新信号（反侦察机场的开关行为）。
5. **GSLB/轮换率统计**：利用 4.4 万快照时序，对每个节点域名统计"解析结果变化频率/多 IP 并存度/CNAME 链长度"→产出"基础设施漂移率"画像（对应 GFW 对抗篇"域名轮换按分钟"反制手段的监控侧量化）。
6. **_rdap 批量注册画像**：注册商/注册时间/注册周期聚类（批量注册+短周期=面板矩阵候选）；与域名角色（订阅域 vs 节点域）交叉。
7. **华为签名命中字段审计**：复核"华为命中"的命中来源分类（节点配置文本/订阅原文/DNS 缓存）——09-16 报告已实锤浏览器 DNS 缓存误报（deepseek.com→HWCSNET 一类）；建议把快照里该字段拆成"配置级命中/解析级命中/噪声"三层，避免旧误报污染新方向。
8. **协议×传输×入口矩阵全量重生成**：研究目录 transports JSON 只有 22 家，用 data/ 快照把 44 家全量重算（type/network/tls/sni/host/path→CDN/专线/中转/直连/藏死五分类），产出 06 号文档之外的"44 机场配置画像标签表"——**这就是流量识别的 ground truth 标签底表**（§五 P0）。

**明确做不到的（离线边界）**：F1-F5/F8 等会话统计判据、JA3/JA4/JA4T、首包比特统计、TLS-in-TLS——全部需要**流量数据**，data/ 快照只有配置与解析/注册面。这正是缺口所在（§五）。

## 五、缺口与下一步建议

### 5.1 缺口清单（按影响排序）

1. **零流量数据**：无 pcap/流日志/首包样本；一切流量侧判据（GFW 五豁免、JA4T、TLS-in-TLS、F1-F8）在本环境从未实测——旧研究停在"方案完整、样本为零"。
2. **采集管线未建**：方案总纲的 P0-P5 路线图是云商租户视角（需自有云账号+镜像规格）；本机视角（连各机场抓首包）从未启动。
3. **JA3/JA4/JA4T 工具链未落地**：文献读透，无实现。
4. **TLS-in-TLS 检测器未实现**：判据已知（`^\x1[67]\x03` 级），无原型。

7. **检测实操手册未落码**：六层漏斗纯文档；行为评分/JA3 统计/帧级指纹均无代码。
8. **图谱工具（graphflow sqlite）未与正文打通**（次要）。

### 5.2 下一步路线建议（流量识别从哪继续）

- **P0（≈1 周，纯离线）**：执行 §四 的 8 项离线分析，产出**44 机场配置画像标签表**（协议/传输/SNI 玩法/端口带/CDN 东家/入口架构/注册面/藏死状态/漂移率）。这是流量识别的标签来源与先验——**我们抓自己监控的机场流量时，每个样本自带 ground truth**。
