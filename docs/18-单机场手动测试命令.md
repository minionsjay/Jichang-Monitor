## 前置（每条命令都依赖）

```bat
cd /d E:\Hermes-Agent\Jichang-Monitor
set HTTP_PROXY=http://[::1]:7890
set HTTPS_PROXY=http://[::1]:7890
set PYTHONIOENCODING=utf-8
```

- 输出**别写 `run.log`**（定时任务在用它，被占用会让 bat 的 `>>` 失败）；想看日志就 `>> run_manual.log`。
- 代理只监听 IPv6 回环 `[::1]:7890`；写 `127.0.0.1:7890` 会直接拒连。
- 客户端型需要客户端在跑；标 `keep_alive` 的会由 `scan-memory` 自己拉起。

## 五、测完的收尾

```bat
rem 看这次拉到多少节点（把 <slug> 换成机场名）
python -X utf8 -c "import json,glob,os;f=sorted(glob.glob(r'data\\<slug>\\*Z.json'))[-1];d=json.load(open(f,encoding='utf-8'));print(os.path.basename(f), len(d['nodes']))"

rem 导出成可导入配置（全量，别加 --only）
python -X utf8 -m airmon.nodeset

rem 套餐余量 / 抽样探活
python -X utf8 -m airmon.quota --only <slug>
python -X utf8 -m airmon.probe
```

## ⚠️ 一个坑

`python -X utf8 -m airmon.nodeset --only <slug>` 会**重写 `nodes/index.json`，把其余机场全丢掉**（只剩 1 台）。
单家导出后必须补跑一次全量恢复：`python -X utf8 -m airmon.nodeset`
