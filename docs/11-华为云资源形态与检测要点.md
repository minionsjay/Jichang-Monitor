# 华为云机场资源形态与检测要点

> 2026-10-20 与用户（华为云平台方视角）对谈沉淀。核心校准：**主流大机场不用华为云做节点**（我们 44 机场 2600+ 节点画像华为命中 0，落地构成 AWS≈30%+腾讯/百度/GCP/Oracle），但**被监管点名的机场大量用华为云**——用户实测检测/监管下发的机场 IP 大部分落在 EIP、GEIP、CDN 加速三类产品上。两个数据不矛盾：分层市场，被点名的是中小机场（图华为云海外区便宜、风控相对松）。

## 1. 机场链路 × 华为云资源位置

```
用户设备 ──①入口/中转──> ②隧道网络 ──③出口/落地──> 目标网站
              │
   ⓪ 业务系统（面板/订阅/支付/客服）── 支撑层，不跑隧道流量
```

| 位置 | 华为云出现频率 | 证据 |
|---|---|---|
| ⓪ 业务系统（面板/订阅/支付） | **最常见**（门面） | alerts.log 79 天全部 13 块华为命中均为面板/注册侧（regip=119.8.242.x），节点侧 0 |
| ① 入口/中转 | **被点名机场常见**（用户实证：EIP/GEIP） | 我们监控的 44 家 = 0；平台方下发 IP 大部分是 EIP/GEIP |
| ③ 出口/落地 | 少（海外区成本高，主流用 AWS Lightsail/Vultr） | 节点画像华为 0 |
| CDN | 入口伪装层/静态加速（用户实证第三类） | — |

## 2. 三类产品的角色、特征与取证抓手

### EIP（弹性公网 IP）→ 节点机的"公网身份"

- **角色**：绑 ECS 的公网 IP；机场租云主机装 xray/sing-box，EIP 即订阅里的节点 server。入口/中转或海外区出口。
- **平台方特征**：流日志里高位端口**长连接**、单连接大字节、多用户扇入同一 IP:port —— 对应检测引擎 J1（长连接大流量）/J2（高位端口）/J3（扇入）。
- **取证**：流日志五特征直接过 `python -m airmon.huawei_detect --in <流日志>` 评分卡。

### GEIP（全域公网 IP）→ 机场的"稳定入口门牌"

- **角色**：跨区域公网 IP，可漂移绑定不同 region 的资源。机场用它做入口——节点被封后 GEIP 背后切 region，订阅零变更、客户端无感。
- **陷阱**：⚠️ 按 IP 封禁常扑空（下发时它可能已漂走）。
- **取证**：**CTS 资源变更审计查 GEIP 绑定变更史**，回溯下发时该 IP 实际绑定的 ECS，再对该 ECS 的流日志跑评分卡。
- 附带观察：GEIP 漂移可能是监控里 churn 异常的来源之一（fastlink 30 天 1.5 万次变更）。

### CDN 加速 → 入口的"伪装层"

- **角色**：节点入口域名（vless+ws+tls 走 CDN 回源）或面板/官网/安装包/订阅静态加速接入 CDN。真实节点机藏在回源后面。
- **陷阱**：⚠️ 边缘 IP 共享，封 IP 会误伤同 CDN 正常客户。
- **取证**：**CDN 回源日志直接暴露真实源站 ECS IP**——一查一个准。域名维度命中（J6），不是 IP 维度。

### 对照速查

| 产品形态 | 链路角色 | 平台方特征 | 取证抓手 |
|---|---|---|---|
| EIP 绑 ECS | 节点/中转机本体 | 出站长连接+高位端口+大字节+扇入 | 流日志五特征（J1-J5 评分卡） |
| GEIP | 稳定入口门牌 | 封 IP 常扑空（已漂移） | CTS 绑定变更史 → 回溯 ECS |
| CDN 加速 | 入口伪装/静态加速 | 边缘 IP 共享，封 IP 误伤 | CDN 回源日志拿真实源站 |

## 3. 面板型 vs 节点型租户（判据设计上的分野）

| | 面板型租户（华为云常见） | 节点型租户（被点名机场） |
|---|---|---|
| 流日志特征 | 入站 443 短连接多、出站少 | 出站长连接高位端口（J1/J2/J4） |
| 有无域名 | 有（面板域名，J6 直接命中） | 多为裸 IP |
| 判据侧重 | 域名关联机场面板域名库+访问模式 | 基建 IP 命中+隧道五特征 |
| 误报风险 | 普通网站业务 | 下载/视频会议 |
