## 1 判定方法与判定规则

### 1.1 判定规则（本次统一口径）

- **① 无需注册即可接入**：公开页面能直接给出可解析的订阅正文或节点串（`vmess/vless/ss/trojan/hysteria`），
  且能用 `run.py pull` 实测出节点数。
- **② 需注册**：面板有注册入口，注册后用户中心能拿到 Clash 订阅链接 —— 用户做完这一步，我方即可接入。
- **③ 不建议接入**：非免费（只有付费档）/ 信誉风险（跑路举报、共用后端）/ 域名与前端形态异常导致无法程序化取订阅。

### 1.2 探测手段（可复现，见附录 B 脚本）

| 手段 | 目标 | 判据 |
| --- | --- | --- |
| `python -m airmon.sitewatch` | 11 家官网/面板域名 | 200/非 200、via=direct/proxy |
| 公开路径探测 | `/robots.txt` `/sitemap.xml` `/free` `/nodes` `/sub` `/clash` `/trial` `/free-nodes` `/knowledge` `/docs` | 内容里是否含节点串；多路径返回**字节数完全相同**即判定 SPA fallback |
| v2board / Xboard 公共接口 | `GET /api/v1/guest/comm/config`、`GET /api/v1/guest/plan/fetch` | 返回 JSON 说明面板类型；`plan/fetch` 里是否含免费档 |
| 首页 JS bundle 挖掘 | 各站 `assets/*.js`、`_next/static/*` | 是否出现「免费 / 试用 / 签到 / 赠送 / trial」及路由标题 |
| 官网文档页 | 快柠檬 `/p/faq`、`/p/about`；各站 `/p/*` | 免费额度、试用规则的一手文案 |
| Telegram 公开频道预览 | `https://t.me/s/<handle>`（无需登录、无需加入） | 最新消息里是否出现节点串/公开订阅；也能读到站方故障公告 |

> 另一类容易被误当"公开订阅"的入口是**公开分享页 / 公开节点页**（如 `xxx.github.io`、`sub.*.pages.dev` 之类）。
> 本次对 11 家 + CSV 扩展候选逐个找过这类页面，能打开的都不是节点页（详见附录 A 补充表），且 CSV 里唯一两条
> 「公开订阅」记录（LEAP、小鲤鱼）本身是**打码的**，无法使用。

### 1.3 网络口径（会影响复现结果）

- 本机代理只监听 IPv6 回环：`http://[::1]:7890`；`http://127.0.0.1:7890` 不通。
- 直连可达：`glados.rocks`、`ikuuu.art`/`ikuuu.top`、`b.smjcgw.com`（三毛）。
- 二手口径说明：`docs/推荐站机场信息库-2026-10-18.csv`（文章日期 2026-06-10）里的「免费线索 / 价格线索 / 文内域名」用于补充
  "注册送多少、要不要邀请码、有哪些备用域"，属**推荐站口径**，与本次实测冲突时一律以实测为准，并在文中标注「推荐站口径」。
- 需走代理：`bak.webitz.net`、`ca.bitznetuk.com`、`falemon.com`、`qq.zjs2025.com`、`ikuajing.xyz`、`baipiaoyes.top`、`dukadi.one`、`dash.xn--mes358aby2apfg.site`、`58.77vy.xyz`、`t.me`。
- 反例（只在浏览器里能开、`requests` 直连不通）：`bitznetuk.com` 走代理返回 403 Cloudflare 盾（`Just a moment...`），其真正的面板是子域 `ca.bitznetuk.com`（200）。
- 浏览器（Chromium）只对直连站点可用；对代理型站点导航会 `ERR_CONNECTION_RESET`/`ERR_TIMED_OUT`，故代理型站点一律用 `requests(proxies=[::1]:7890)` 只读探测。

## 2 ① 已接入并实测有节点（0 家）

**本轮 0 家。** 11 家候选全部落在 ②/③，因此没有可 `pull` 的订阅链接，也就没有节点数可报。

> 说明：这不是"没试"，而是"试完确认不存在"。逐家证据见 §5 附录 A（同一站点不同路径返回同一份 index.html 的字节数对比、
> 以及各站 `guest` 接口的原始返回）。若直接把某家的落地页当成"公开节点页"接进去，`pull` 只会拿到 0 节点或占位节点
> （`collect_direct` 会用 `_filter_placeholders` 过滤掉占位节点），属于假接入。

**一旦用户完成 §3 的任一注册，接入是两条命令：**

```bash
# 方式 A：机场还不存在（会同时写 airports.yaml + credentials.yaml + seeds.txt）
python -X utf8 run.py add-airport --name <slug> --display "<中文名>" --type direct \
    --sub-url "<面板复制的 Clash 订阅链接>" --domains "<主域名>;<备用域名>"
python -X utf8 run.py pull --airport <slug> -v

# 方式 B：slug 已存在，只补订阅链接
python -X utf8 run.py set-sub --airport <slug> --sub-url "<订阅链接>"
python -X utf8 run.py pull --airport <slug> -v
```

命令依据（本次读源确认，未执行以避免改动仓库状态）：
- `run.py:1199 cmd_add_airport()`：`--type auto|v2board|sspanel` 都会落成 `type: direct`，即 `collect_direct()` 走 `subscription.url` + UA `clash.meta`；
- `run.py:1270 cmd_set_sub()`：只写 `credentials.yaml` 的 `sub_url`（可选 `panel/email/password`）；
- `run.py:533 cmd_pull()`：`slug` 必须在 `credentials.yaml` 里，`_pull_one()` 的直连分支只依赖 `sub_url`。
